# 📂 Histórico Penal - Banco de Dados

Este projeto contém a modelagem e um banco de dados voltado ao armazenamento de informações sobre indivíduos, seus históricos criminais, registros de audiências judiciais,  manipulado pelo python para pesquisa e prognóstico com a ajuda de I.A.

## 📌 Objetivo

Registrar e consultar dados de pessoas com:

- Dados demográficos (nome, idade, gênero, raça, local de residência)
- Histórico penal (tipo e número de crimes)
- Histórico de audiências (datas, resultados, observações)

## 🧱 Estrutura de Tabelas

- **Pessoa**: informações básicas de cada indivíduo
- **HistoricoPenal**: tipos e número de crimes associados à pessoa
- **Audiencia**: registros de audiências judiciais
